### Bespoke Creative Direction & Strict Anti-AI-Slop Mandate:
1. **Strict Anti-AI-Slop Policy (Non-Negotiable)**:
   - **BANNED PATTERNS**: Never ship generic AI-generated templates — no default purple/indigo/violet neon gradients on `#0f172a` dark backgrounds, no generic 3-column emoji feature cards, no unstyled boilerplate dashboards, and no placeholder "Lorem ipsum" copy.
   - Every interface must look like it was art-directed by a world-class design studio specifically for the project's domain declared in `.agents/rules/project-context.md`.
2. **Domain-Authentic Art Direction & Visual Craft**:
   - **Broadcast Sports, Tournament & Live Media Portals**: High-impact condensed display typography, pitch/turf emerald or stadium floodlight contrast, live scoreboard tickers, interactive tournament brackets, match telemetry cards, and kinetic micro-interactions.
   - **High-Trust Precision FinTech & Trading Platforms**: Crisp tabular numerals (`font-variant-numeric: tabular-nums`), 1px hairline structural grids, high-contrast semantic status badges, institutional trust palettes, and zero visual clutter.
   - **Editorial Luxury, E-Commerce & Cultural Portals**: Expressive serif/sans-serif font pairings, warm tactile surfaces, asymmetric Bento grids, custom SVG illustrations/badges, and choreographed scroll/view transitions.
   - **High-Craft Developer Tools & Enterprise SaaS**: Keyboard-first command palettes (`Cmd/Ctrl+K`), dense scannable tables, instant optimistic UI feedback, and clear loading/skeleton/empty/error states.
3. **Engineering Excellence, Performance & Accessibility**:
   - Build strictly inside your owned paths (typically `src/ui/`, `src/client/`, `src/components/`, `src/styles/`, `src/media/`, `public/`, `index.html`) consuming the Phase 1 contracts in `src/types/`.
   - Enforce Core Web Vitals budgets (`LCP < 2.0s`, `CLS < 0.05`, `INP < 200ms`), mobile-first responsive layouts, semantic HTML5 landmarks, full keyboard navigation, focus-visible rings, and **WCAG 2.1 AA** color contrast.
4. **Structured 4-Part Hand-off Ticket Protocol**:
   - Report completed work using:
     1. `[CONTEXT & INPUT CONTRACTS]`: Design tokens and Phase 1 TypeScript/API contracts consumed.
     2. `[OWNED FILE BOUNDARY]`: Exact UI/component/style/asset files created or modified.
     3. `[EXCELLENCE & ACCEPTANCE CRITERIA]`: Confirmation of bespoke domain aesthetic (zero AI-slop), responsive breakpoints, and WCAG AA accessibility.
     4. `[DOWNSTREAM HANDOFF]`: Hand off to `security-privacy-lead` (XSS/CSP check) and `qa-release-lead` (UI build, E2E & accessibility gate).
